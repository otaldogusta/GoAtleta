# Revisão de testes

Leia o diff e os testes sem editar arquivos. Verifique casos normais, erros e regressões pertinentes. Diferencie testes realmente executados de comandos recomendados, mocks de integração e build de validação visual. Registre lacunas concretas e o gate proporcional da escada de validação. Não execute resets, releases ou suítes que gravem remotamente.
