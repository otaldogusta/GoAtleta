# Revisão de interface e experiência — 13/11/2026

Este lote aplica correções no app local a partir da revisão por abas. O
inventário de auditoria continua sendo o mapa de cobertura e de propostas.

| Área | Comportamento local |
| --- | --- |
| Planejamento | No mobile, o ponto de partida mostra a turma, a data e “Criar plano”. A biblioteca abre pela mesma tela. Criar abre o editor sem marcar o plano como aplicado. |
| Periodização | A tela inicial permite escolher a turma. Mês fora do ciclo, ciclo encerrado e configuração pendente têm estados próprios. O calendário separa previsão, prontidão, aplicação e conclusão com evidência. |
| Turmas | Filtro de unidade permite ler o nome em telas estreitas. A busca sem resultado permite limpar filtros. Na ficha sem plano, “Montar plano”, Chamada e Relatório permanecem à vista. |
| Gestão | No mobile, os indicadores ocupam duas colunas. Pendências aparecem com a próxima ação; erros de carga mostram a instituição e permitem tentar de novo. |
| Avisos | Filtros se ajustam à largura. Erro de carga não é apresentado como caixa vazia; a tentativa pode ser refeita no mesmo recorte. Uma atualização que falha mantém a última lista conhecida para o mesmo recorte. |
| Regulamentos | A versão em vigor e as cláusulas precedem as fontes. A comparação só aparece com pelo menos duas versões. Falha parcial de sincronização é comunicada na fonte, com o histórico carregado preservado. |
| Quadra Visual | No editor web em retrato, até 700 px, o **+** da barra inferior abre Ferramentas na mesma ficha de Ajustes, Etapas e Biblioteca. Teclado, Escape e retorno de foco fazem parte do fluxo. Em paisagem, desktop, nativo e modo de leitura, permanecem os controles correspondentes. |
| Agenda | Na composição compacta, o Assistente tem acesso no cabeçalho; a área inferior fica livre para adicionar eventos. |
| Relatórios | O resumo distingue registros de presença de aulas com chamada. A fonte diária agrega por turma e data: duas aulas da mesma turma no mesmo dia contam como uma unidade nesse indicador. |
| Acessos | Filtro e página delimitam a seleção. Erro e lista vazia são distintos. Cada pedido anuncia pessoa, e-mail, instituição, produto e status; aprovar ou recusar exige um pedido visível e pendente. |
| Evidências | A revisão de uma síntese exige que instituição, pergunta e artigos selecionados ainda correspondam ao que foi gerado. |

Na conferência móvel com dados fictícios, foram observados a ficha da Quadra,
filtro e ficha de Turmas, Gestão em erro, Avisos arquivados vazios,
Regulamentos sem fontes, as entradas de Planejamento e Periodização, a abertura
do Assistente na Agenda, o resumo de Relatórios e Acessos sem resultado. Esses
estados não certificam todas as combinações de perfil, dispositivo ou dados.
